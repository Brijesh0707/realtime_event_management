Real-Time Event Management

Overview

Real-Time Event Management is a web application that allows users to register, log in, view events, join events, and create events in real time. When a user creates an event, it is instantly broadcasted to all users' dashboards. The application utilizes WebSockets for real-time updates.

Tech Stack

Frontend:

React.js

Tailwind CSS

Socket.io (WebSockets for real-time updates)

Context API (useContext for state management)

Backend:

Node.js

Express.js

MongoDB (or any database of choice)

Socket.io (for real-time event updates)

MVC Architecture

Features

User Authentication (Register/Login)

View all events

Join events in real-time

Create events

Real-time event updates

Dashboard updates for all users when a new event is created

Track real-time event attendance

Installation

Prerequisites

Ensure you have the following installed:

Node.js

npm or yarn

MongoDB (if using locally)
